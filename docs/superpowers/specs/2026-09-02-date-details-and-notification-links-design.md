# Детали свидания и переходы из уведомлений

## Цель

Любое свидание в разделе «Планы» открывается в окне деталей. Участники видят
актуальные сведения, а организатор может передать партнёру точное время и
комментарий. Уведомление и push ведут в это же свидание.

## Область этой доработки

- Клик по карточке открывает окно деталей независимо от полноты сведений.
- Окно показывает тип, название, текущие точные дату и время, комментарий и
  понятное состояние, если точное время ещё не назначено.
- Редактирование доступно только организатору: он может указать точную дату,
  время и комментарий и отправить детали партнёру.
- Сохранение точных деталей создаёт или обновляет календарное приглашение,
  отправляет письмо с `.ics`, внутреннее уведомление и push.
- Уведомления хранят ссылку на свидание. Клик по записи в колокольчике или
  push открывает соответствующее окно деталей по URL `?date=<id>`.

## Права и уведомления

Организатор определяется существующим правилом: при режиме `self` это автор
свидания, при режиме `partner` — второй участник. Партнёр видит детали только
для чтения. Если точной даты ещё нет, сохранение деталей недоступно никому,
кроме организатора; до первого точного времени `.ics` не формируется.

При отправке или обновлении деталей уведомляется только второй участник
пространства. Уведомление помечается прочитанным после перехода в окно
свидания.

## Данные и совместимость

В таблицу `notifications` добавляется nullable `date_id`; старые уведомления
без него по-прежнему открывают только список. API уведомлений возвращает
`dateId`, а push передаёт URL со значением `date`.

Текущие nullable-поля `starts_at` и `event_date` остаются без изменений.
Будущая работа добавит отдельное поле примерного периода и раздел «Банк идей»;
эта доработка их не моделирует и не меняет текущую форму создания свидания.

## Проверки

- Тесты API: `date_id` возвращается в уведомлении, принадлежность свиданию
  проверяется и отправка деталей создаёт ссылочное уведомление.
- Тесты интерфейса: клик по карточке открывает детали; клик по уведомлению
  открывает нужную карточку и помечает уведомление прочитанным.
- Существующие тесты календаря подтверждают вложение `.ics` при наличии
  точного времени.
